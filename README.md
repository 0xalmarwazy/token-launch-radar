A token launch radar that ranks pre-token DeFi protocols by implied value, derived from each protocol's own TVL, 7-day growth and tenure without a token, with a concrete farm plan for every row, in a sortable and filterable dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json
```
